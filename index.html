KEC 분기회로 계산서테스트 버전

서적판(기술지침 절차 재현)과 실무판(단순화)으로 같은 부하를 계산하고 결과를 서로 검증합니다.

처음 오셨나요? 아래 “30초 체험” 버튼 하나만 누르면 됩니다. 열리는 화면의 결과 요약 카드가 계산 결과입니다.

30초 체험

전동기 45kW, 3상 380V, Y-Δ 기동 예제(M3)가 입력된 상태로 열립니다. 아무것도 입력하지 않아도 결과가 나와 있습니다.

M3 예제 열어 보기 열린 화면에서 값을 바꿔 보다가 처음 상태가 필요하면 PDF 예시값 복원 버튼을 누르세요.

내 부하로 계산하는 순서

  1. 부하 조건을 넣고 계산서 찾기부하 종류, 전압, 용량, 기동방식을 고르면 맞는 계산서를 추천합니다.INDEX 열기 →
  2. 같은 조건을 실무판에도 입력3개 탭(공통 조건, 비전동기, 전동기). 공통 조건 탭의 전원·변압기 값을 먼저 맞춥니다.실무판 열기 →
  3. 두 결과를 나란히 놓고 판정설계전류, 차단기 정격, 케이블 굵기, 보호협조 네 가지를 비교합니다.판정표 보기 →

검증 예제 3건 (결과가 어떻게 나오는지 먼저 확인)

G2 비전동기 20kVA두 계산서 결과가 일치하는 예서적판 G2 →
M2 전동기 22kW굵기가 달라지는 예 (16㎟ 대 25㎟)서적판 M2 →
M3 전동기 45kW Y-Δ1차/2차 이중배선, 일치하는 예서적판 M3 →

실무판에 같은 값을 넣는 방법과 결과 비교표는 사용 가이드에 있습니다.
