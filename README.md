# KEC 간선 및 분기회로 계산서 (테스트 버전)

서적판(기술지침 KECG 1702-2019 절차 재현)과 실무판(단순화)으로 같은 부하를 계산하고 결과를 서로 검증하는 HTML 계산서 모음입니다.

## 처음 실행할 때
1. `index.html`을 엽니다 (GitHub Pages 주소 또는 파일을 내려받아 더블클릭).
2. 화면의 **30초 체험** 버튼을 누릅니다. M3 예제가 입력된 채로 열리며 결과 요약이 바로 보입니다.
3. 내 부하로 계산하려면 `finder/index.html`에서 조건을 입력해 계산서를 고릅니다.
4. 같은 조건을 `practical/index.html`(간선은 `practical/feeder.html`)에도 넣고 결과를 비교합니다. 비교 방법은 `guide.html`에 있습니다.

## 구성
- 서적판 15종: 분기회로 12종 `g1~g5.html`(비전동기), `m1~m7.html`(전동기) + 간선 3종 `f1~f3.html`
- 통합 계산서(테스트): `tree.html` — 변압기·저압반·간선·분전반·분기 일괄 입력·계산, 인쇄는 `KEC_print.html`·`KEC_ref_print.html`·`print_engine_cc.js`, 표 글꼴 `fonts/`
- 서적판 외 자체 예제: 간선 `f0.html` (일반부하·전동기 없음)
- 실무판 2종: 분기회로 `practical/index.html` (계산 순서 부하 → 차단기 → 케이블 → 보호도체, 계산 옵션 선택 가능, 케이블 굵기는 정식 전압강하로 자동 선정), 간선 `practical/feeder.html` (F1·F2·F3 예제 선택, 조건 → 설계전류 → 보호장치 → 도체 단면 → 보호도체 순서)

## 주의
- 폴더 구조를 바꾸지 마세요. `kec_data.js`, `print_engine.js`, `print_engine_cc.js`, `fonts/`를 상대 경로로 불러옵니다.
- 산출근거의 수식 표시(MathJax)는 인터넷 연결이 필요합니다.
- 테스트 버전입니다. 설계 제출 전 근거 문서와 대조해 확인하세요.
