# KEC 분기회로 계산서 (테스트 버전)

서적판(기술지침 KECG 1702-2019 절차 재현)과 실무판(단순화)으로 같은 부하를 계산하고 결과를 서로 검증하는 HTML 계산서 모음입니다.

## 처음 실행할 때
1. `index.html`을 엽니다 (GitHub Pages 주소 또는 파일을 내려받아 더블클릭).
2. 화면의 **30초 체험** 버튼을 누릅니다. M3 예제가 입력된 채로 열리며 결과 요약이 바로 보입니다.
3. 내 부하로 계산하려면 `finder/index.html`에서 조건을 입력해 계산서를 고릅니다.
4. 같은 조건을 `practical/index.html`에도 넣고 결과를 비교합니다. 비교 방법은 `guide.html`에 있습니다.

## 주의
- 폴더 구조를 바꾸지 마세요. `kec_data.js`, `print_engine.js`를 상대 경로로 불러옵니다.
- 산출근거의 수식 표시(MathJax)는 인터넷 연결이 필요합니다.
- 테스트 버전입니다. 설계 제출 전 근거 문서와 대조해 확인하세요.
