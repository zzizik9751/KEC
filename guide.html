0이 도구는 무엇인가

분기회로의 설계전류, 차단기 정격, 케이블 굵기, 보호협조를 자동으로 계산하는 HTML 계산서 모음입니다. 계산 방식이 다른 두 버전을 함께 두어, 한쪽 결과를 다른 쪽으로 확인할 수 있습니다.

서적판12종 (G1~G5, M1~M7)

기술지침 PDF 5.1.2~5.1.13의 절차를 그대로 재현합니다. 병렬도체, BUS DUCT, Y-Δ 이중배선도 PDF대로 다룹니다. PDF 예시값과 일치하는 것이 목적입니다.

쓰는 때 인허가·감리 제출, 근거 확인, PDF 학습

실무판1종 (3개 탭)

실무 관행으로 단순화했습니다. XLPE 케이블, 산업용 MCCB, 단일 단심, 변압기 직결 단락 가정이 전제이고, 계산 순서는 부하 → 차단기 → 케이블 → 보호도체(PE)입니다.

쓰는 때 일상 설계, 견적, 초기 검토

검증의 원리

1같은 부하·포설 조건을 두 계산서에 입력
→
2핵심 4값 비교
IB · In · S · 보호협조 판정
→
3같으면 확정, 다르면 판정표(7장)로 원인 확인

두 버전은 서로를 대체하지 않습니다. 비교 레포트의 운영 원칙은 병행 유지입니다. 다만 실무판은 보호협조를 항상 만족하도록 설계되어 있어, 서적판과 굵기가 다를 때는 실무판이 한 단계 굵게 나오는 쪽이 의도된 동작입니다.

1준비와 열기

설치는 없습니다. 폴더를 열어 HTML 파일을 브라우저로 열면 됩니다. Chrome 또는 Edge를 권장합니다.

폴더 구조

KEC/
├─ index.html               ← 시작 화면
├─ guide.html               ← 이 가이드
├─ finder/index.html        ← 부하조건으로 계산서 찾기 (INDEX)
├─ practical/index.html     ← 실무판 (3개 탭)

HTML이 kec_data.js와 print_engine.js를 상대 경로로 불러옵니다. 폴더를 통째로 옮기면 괜찮습니다. HTML 파일만 따로 꺼내면 계산이 동작하지 않습니다.

인터넷 연결

산출근거의 수식 표시는 MathJax를 인터넷에서 불러옵니다. 오프라인이면 수식이 $ … $ 원문 그대로 보이지만 계산 결과 자체는 정상입니다. 인쇄·제출용 산출근거는 인터넷이 연결된 상태에서 만드세요.

25분 시작

부하 하나를 넣어 두 계산서의 결과를 확인하는 가장 짧은 경로입니다.

  1. INDEX.html 열기

    finder/index.html을 더블클릭합니다.

  2. 부하조건 입력

    부하 종류, 전기방식, 전압, 용량(kW), 전동기라면 기동방식을 고릅니다. 아래 두 탭에 서적판 추천과 실무판 추천이 동시에 준비됩니다.

  3. 서적판 추천에서 계산서 열기

    추천된 계산서(예: M3)의 계산서 열기를 누릅니다. 새로 열린 화면의 결과 요약을 메모합니다.

  4. 실무판 열기

    INDEX의 실무판 추천 탭에서 실무판 열기를 누르고, 같은 조건을 입력해 결과 요약을 메모합니다.

  5. 비교

    설계전류 IB, 차단기 In, 케이블 굵기 S, 보호협조 판정 네 가지를 나란히 놓고 7장 판정표로 읽습니다.

INDEX는 길잡이입니다

INDEX는 입력 조건에 맞는 계산서를 안내하기만 하고 계산하지는 않습니다. 실제 수치는 각 계산서 화면에서 나옵니다.

3실무판사용법

탭 ① 공통 조건을 한 번 설정하고, 부하 종류에 따라 ② 비전동기 또는 ③ 전동기 탭에서 계산합니다.

탭 ① 공통 조건

전원과 변압기 값은 단락전류와 차단용량(Icu) 계산의 기준이며, 두 분기 탭이 같이 사용합니다.

탭 ② 비전동기 / 탭 ③ 전동기

  • 계산 옵션 (전동기 탭) ① 기동방식 계수 C 적용 여부, ② Y-Δ 전환 돌입 고려 여부, ③ 보호도체 선정 기준(공통 조건 탭)을 고를 수 있습니다. ①을 “미적용”으로 두면 서적판(M1~M5)과 같은 방식으로 과부하 정격을 계산합니다. Soft Start·Inverter는 전류제한 방식이라 이 옵션과 무관하게 전류제한값 λ를 씁니다.

공통 조건 탭의 기본 케이블·공사방법과, 분기 탭의 케이블 종류·공사방법은 각각 따로 입력하는 칸입니다. 비교할 때는 두 곳 모두 서적판 조건과 맞추세요.

6검증 실습 3건

아래 입력값으로 두 계산서를 직접 돌려 보면서 비교 방법을 익히세요. 서적판은 파일을 열었을 때 들어 있는 값이 PDF 예시값이므로 따로 입력할 필요가 없습니다. 실무판 입력값을 같은 조건으로 맞추면 됩니다.

이 3건의 값에 대해

이 값들은 가이드를 만들면서 실제 파일에 같은 입력을 넣어 얻었습니다. 서적판 값은 각 계산서를 열었을 때 기본으로 들어 있는 값의 결과입니다. 사용 중인 파일이 수정되었다면 값이 달라질 수 있으니 직접 한 번 돌려 확인하세요.

7비교 결과 판정표

두 계산서의 IB, In, S, 보호협조 판정을 놓고 아래 표로 읽습니다.

관찰해석할 일
IB, In, S가 모두 같다정상두 계산서가 같은 결론입니다.확정. 제출용 근거는 서적판 산출근거를 사용합니다.
실무판 S가 더 굵다원인 확인서적판의 보호협조가 “부적정”이면 실무판이 이를 해소한 것일 수 있습니다.서적판 판정을 확인합니다. 서적판도 “적정”인데 실무판만 굵다면 길이, 공사방법, 배열, 온도 입력이 같은지 점검합니다.
실무판 S가 더 가늘다입력 불일치 의심비교 레포트는 실무판이 서적판보다 가늘게 나오지 않도록 설계했다고 설명합니다.배선 조건, 회선수, 주위온도, 심선수·배열 입력을 다시 맞춥니다.
서적판이 병렬·BUS DUCT·ACB를 쓴다 (G5, M6, M7)직접 비교 불가실무판은 병렬·BUS DUCT를 지원하지 않습니다.실무판은 단일 케이블 결과와 400A 경고(8장)를 참고용으로만 봅니다.
Icu, F1, F2가 다르다비교 제외실무판은 간선 임피던스를 무시하고, 보호장치 종류도 다릅니다.단락전류와 차단용량은 서적판 값을 기준으로 합니다.
전압강하가 다르다조건 확인단면적이 다르거나 배선을 나누는 방식이 다르면 값이 달라집니다.두 값 모두 허용치 이내인지만 확인합니다.

8실무판의 400A 경고

실무판은 차단기 정격이 400A를 넘으면 경고하고 부하 분리를 권고합니다. 단일 분기로 쓰기엔 차단기·케이블·시공 부담이 크다는 신호입니다.

  • 한도 가이드는 비전동기 약 250kVA, 전동기 약 220kW입니다. 입력한 효율·역률에 따라 경계가 달라지므로 위 예처럼 220kW에서도 경고가 나올 수 있습니다.
  • 비전동기 250kVA, 3상 380V, F-CV 1C F2 50m 입력은 IB 379.8A, In 400A로 한도 경계에 걸리며 경고는 나오지 않습니다.
  • 이 예의 기동 전압강하는 8.55%로 “부적정”이 함께 표시됩니다. 경고와 별개로 판정 한 줄도 확인하세요.

  2. (서적판) 출력 미리보기

    브라우저 인쇄 창이 열립니다. 대상 프린터를 “PDF로 저장”으로 바꾸면 파일이 됩니다.

서적판과 실무판의 인쇄 차이

서적판은 전용 A4 출력 엔진(print_engine.js)으로 페이지를 나눕니다. 실무판은 브라우저 기본 인쇄를 사용합니다. 인허가·감리 제출용은 서적판 출력을 쓰세요.

10알려진 한계

결과를 해석할 때 알고 있어야 하는 제한입니다.

  • 실무판 단락전류는 크게 나올 수 있습니다. 간선 임피던스를 무시하므로 서적판보다 큽니다. 3건 모두 F1이 서적판의 3~5배입니다(M3는 59,321A 대 11,793A). 이 때문에 실무판 Icu가 더 큰 정격으로 선정됩니다.
  • 보호장치 종류가 다릅니다. 서적판 G2는 주택용 MCB(Icu 16kA), 실무판은 산업용 MCCB(Icu 50kA)입니다. Icu는 비교 대상이 아닙니다.
  • MCCB 동작시간 tn은 0.1초 가정값입니다. 특성곡선 이미지 5종(MCC 특성곡선*.png)의 데이터화가 아직 남아 있어, 단락보호 판정의 정밀도에 한계가 있습니다.
  • 실무판 미지원 항목 병렬도체, BUS DUCT, ACB, 복수회로, PVC 계열 케이블(IV·CV·VV)은 지원하지 않습니다.
  • 유지보수 시 kec_data.js를 수정한 뒤에는 파일 끝이 잘리는 일이 반복되었으므로 node --check kec_data.js로 구문을 확인하세요.

11문제 해결

화면은 열리는데 결과가 비어 있습니다

공용 파일을 못 찾는 경우입니다. HTML 파일이 kec_data.js, print_engine.js와 같은 폴더 구조 안에 있는지 확인하세요. 실무판은 practical/ 폴더 안에서 위 폴더의 파일을 불러옵니다.

산출근거에 $ 기호와 역슬래시가 그대로 보입니다

수식 표시용 MathJax를 불러오지 못한 상태입니다. 인터넷에 연결한 뒤 화면을 새로고침하세요. 계산 결과는 영향을 받지 않습니다.

서적판 입력을 바꿔 보다가 기준값을 잃었습니다

PDF 예시값 복원 버튼을 누르면 기본 상태로 돌아갑니다.

실무판과 서적판의 굵기가 다릅니다

7장 판정표를 따라 서적판의 보호협조 판정부터 확인하세요. 입력 조건(길이, 공사방법, 배열, 온도, 회선수)이 같은지가 그다음입니다.

어느 쪽 결과를 설계서에 쓰나요

비교 레포트의 권장은 인허가·감리 제출에는 서적판, 일상 설계와 견적에는 실무판입니다. 두 결과가 다를 때의 최종 채택은 설계 책임자가 판단할 사항입니다.
