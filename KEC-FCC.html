변압기 용량 산정 계수 (전기실 · 변압기 용량 계산서)

P[kVA] = Σ수용부하[kVA] × 여유율 ÷ 효율 → 표준용량으로 올림 채택 (여유율은 변압기별로 계산서에서 선택, 기본 1.1). 효율표 모드: 후보 용량마다 표의 효율(50kVA~3150kVA, 용량 이상 첫 행)을 적용해 반복 판정

최소 규격 설정 (간선·분기 차단기 AF·AT / 도체 굵기) — 0 입력 시 미적용

AF는 차단기 프레임 최소값(차단용량 선정 때 이 프레임 이상에서 선정), AT는 정격전류 최소값입니다. 입력값은 표준 정격(차단기)·표준 단면적(도체)으로 올림 적용되며, 자동 선정값이 이보다 작을 때만 최소값으로 상향됩니다. 수동 지정(강제)값이 있으면 그것이 우선합니다.

배선 계획 기준 (케이블 구성 · 보호도체 · 전선관 · 전압강하)

  • 다심 적용 최대 굵기: 이하 다심, 초과 단심 자동 계획 — 같은 포설 장소의 다심/단심 공사방법 짝(공중 E/F, 덕트 B2/B1, 관내 A2/A1) 적용, 현재 일반부하 간선(F0)과 전선관 가닥수에 반영
  • 보호도체: 표 142.3-1(선도체 단면적 기준) 또는 142.3.2 계산식
  • 후강전선관 충전율: KEC 상한 1/3(33%), 권장 30%
  • 간선 전압강하 판정: 구간별 = 간선마다 허용 VD(서적판) / 배분 = 저압반 기준 메인·서브·분기 4/2/2% + 분기 실제 VD 여유 상향
