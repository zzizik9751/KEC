분기회로 계산서 (KEC)

계산순서: 부하 → 차단기 → 케이블 → 보호도체(PE). 계산 옵션(기동방식 계수·Y-Δ 전환 돌입·PE 기준)을 선택할 수 있으며, 옵션을 ‘미적용’으로 두면 서적판(M1~M5)과 같은 값이 산출됩니다. 산업용 MCCB·XLPE 케이블 단일도체 한정. 간선 임피던스는 변압기 직결 가정으로 단순화(보수적). 차단기 정격이 400A 초과 시 부하 분리 권고. 단상은 3.7kW(비전동기 3.7kVA)까지만 지원하며, 초과 시 3상으로 선정하십시오.

계산 조건 (공통)

공통 조건 — 전원·변압기·기본값

한 번 설정하면 비전동기·전동기 탭에서 자동 사용됩니다. 단락전류 산출의 기준값.

전원 / 변압기

기본값 (각 탭에서 그대로 사용·재설정 가능)

계산 옵션 — 보호도체(PE) KEC 142.3.2 / 표 142.3-1

표 142.3-1: 선도체 S≤16㎟ → S, 16<S≤35 → 16㎟, S>35 → S/2. 계산식: SPE=IF2,max·√tn/K·a (tn=0.4 s, K=143, a=1.25). 두 방식 모두 보호도체 종류는 F-GV(PVC)로 가정.
변압기 직결 가정: 실무 단순화상 간선 임피던스는 무시합니다. 단락전류는 전원+변압기+분기케이블만으로 계산되어 보수적(약간 더 큰 값)으로 산출됩니다. 이로 인해 차단기 차단용량(Icu)은 안전 마진이 약간 확보됩니다.
